# 研究与设计记录

日期：2026-09-27。

用户目标：以算法为驱动、场景为目标，统一展示、调整、验证、演示和解释；理解参数变化的原因和复用边界。

采用七个独立教学实验，而不重复嵌入上游场景。场景入口提供需求与推荐算法组合；算法入口提供真实计算、画面、参数、A/B 参考、公式、检查和迁移说明。

## 教学取舍

- 二维 IFFT 使用 32 × 32 方向 Gaussian 谱；共轭对称保证实值，不能称为 JONSWAP 复现。
- 浅水采用压力驱动的保正水量通量模型，省略完整动量平流；自动细分时间步，边界净交换进入水量账本。
- 平流使用给定速度场；严格区分显式消散、插值耗散与不保证总量守恒。
- 湿度与水膜为无量纲状态，不等价于真实渗流或毫米级水深。
- 水体光学验证反射近似、折射和均匀介质吸收；不把示意亮纹称为物理焦散。
- 浪唇是参数化剖面与弹道点，未耦合浅水或三维水幕碰撞。
- 材质使用独立 value noise / fBm，在球体上比较单平面和三平面投影。

## 复用层次

调参数改变现有行为；改地形、边界和触发源属于场景适配；瀑布、船体浮力、泥沙侵蚀等需要新增模型。算法检查验证局部数学关系，不验证最终视觉真实性或工程精度。
