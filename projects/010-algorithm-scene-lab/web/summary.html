THE RESEARCH IN FIVE QUESTIONS

效果、模块、用途，以及对你的价值。

呈现效果
原库呈现浪涌、冲滩回流、绕石白沫、湿沙反光；ShoreBreak 还表达翻卷水幕与水下气泡。我们的实验室把这些效果拆成可调的 A/B 教学画面、数值和曲线，不复现原站完整画质。
内部模块
七组运行模型：波浪、浅水、输运、湿度、光学、翻卷与喷溅、噪声与三向投影；配套八个场景入口、参数与种子管理、共同时间、24 项局部检查、实验链接与记录导出。总图另梳理体积效果及模块连接。
使用场景
用于学习水面图形算法、比较参数影响、验证视觉原型和评估模块复用；目标覆盖海岸、湖池、沟渠、雨后地面、水下、冲浪、溪流泡沫与岩石材质。
可扩展产品方向
可发展为图形学交互课程、水效果参数与素材编辑器、沉浸海岸展示、场景视觉预演工具。现有实验提供原理和验证基础，产品化仍需课程或资产管理、GPU 渲染、模块接口与设备适配。
对我的意义
建立“场景目标 → 算法组合 → 参数验证 → 模块复用”的判断方法：能解释画面来源，区分调参数、适配地形、连接系统和新增模型，形成后续三维交互项目的可复用知识与实验资产。

02 / THE MENTAL MODEL

核心理解：组合，还要连接。

01

先问水怎样动

波谱与解析波生成起伏，浅水模型计算地形上的流量，独立水幕表达翻卷。它们解决不同尺度的问题。

02

再问水怎样被看见

水面斜率改变法线，法线与相机方向改变反光；光在水里走得越远，颜色衰减越明显。

03

让细节拥有来处

冲击产生白沫与喷溅，流速搬运泡沫，水退后留下湿痕。细节读取同一套状态，才能跟上水的运动。

04

把通用理解成可组合

已有行为可以调参数；换岸线和物体要适配地形与边界；倒水、浮力、侵蚀等需求需要新增模型。

以“浪打到石头”为例

地形改变浅水流动 → 冲击处生成白沫和水花 → 白沫跟随流速 → 水退后保留湿度 → 同一水面法线、相机与光源决定反光。

深度既参与运动模型，也影响水中光程；相机角度改变看到的反射比例；光源、曝光与素材也影响画面。最终效果并不只由几个滑块决定。

04 / ALGORITHM ATLAS

十个模块，七组动手实验。

C 表示 coastal-simulation，S 表示 ShoreBreak。按计算职责拆分，因此光学和粒子会映射到同一组教学实验。

01 / 运动

波形合成

解析波叠加 / 频谱 + IFFT

把频率、方向和能量转换成高度与斜率。FFT 是变换工具，海况来自所选波谱与参数。

关键参数
振幅、波长、方向、风浪谱、随机种子
可见效果
长涌、短浪、多尺度起伏；斜率提供反光所需的法线。
可复用到
海洋背景、湖泊、水池；更真实的风场与远近细节。
查看原库分工、教学边界与观察方法

原库：C：四组解析波；S：三层 FFT 风浪，主要破浪另由事件驱动。

教学：① 波浪：四波叠加 / 32² Gaussian 教学谱

边界：教学频谱不是完整 JONSWAP；单值高度场无法表达倒卷水幕。

观察：固定方法、时间与种子，只把振幅加倍，比较高度 RMS。

02 / 运动

浅水与湿干边界

压力梯度 / 有限体积 / 保正通量

以地形、水深和水平流动为状态，通过格子之间的通量更新水量。

关键参数
地形高程、边界水位、摩擦、格距、时间步
可见效果
冲滩、退水、绕石、浅溪流动、移动的湿干边界。
可复用到
沟渠、浅水景观、薄层积水；需重新配置边界与地形。
查看原库分工、教学边界与观察方法

原库：C：CPU Worker，可选 Wasm；S：GPU 中心迎风浅水求解。

教学：② 浅水：48 × 28 保正水量通量模型

边界：教学版省略非线性动量平流；守恒通过不代表工程预测准确。

观察：抬高障碍，观察绕流；核对各自水量收支，而不是比较两侧水量绝对值。

03 / 运动

翻卷浪唇与水幕

事件调度 / 参数化几何 / 弹道

按破浪阶段塑造浪峰，独立网格表达伸出、翻卷与落下的水幕。

关键参数
事件时刻、浪唇高度、发射速度、重力
可见效果
向前翻卷的浪头、浪腔、落水冲击与可控镜头。
可复用到
冲浪镜头、水幕特效；接入冲击位置与水量、动量交换。
查看原库分工、教学边界与观察方法

原库：S：LipRibbon 独立网格，冲击连接浅水；C：无独立翻卷水幕。

教学：⑥ 翻卷：二维剖面与独立弹道轨迹

边界：不是任意波浪自发破碎；教学版未连接浅水或三维自碰撞。

观察：只增加重力，观察落水时间缩短和前伸距离减小。

04 / 细节

泡沫生成与输运

源项 / 回溯采样 / 插值 / 消散

冲击等条件产生泡沫；沿速度反向采样上一帧浓度，再按寿命衰减。

关键参数
生成阈值、速度场、寿命、采样精度
可见效果
随流白沫、碎泡纹理、拉长的示踪条带。
可复用到
水面染色、漂浮纹理；守恒污染物需采用相应输运模型。
查看原库分工、教学边界与观察方法

原库：C / S：生成与搬运配合；白沫要跟随实际水流与冲击。

教学：③ 输运：给定二维速度场的被动标量

边界：教学版不求速度；插值会耗散，任意流场不保证严格总量守恒。

观察：先关闭消散观察插值模糊，再只增加消散，区分两种变淡原因。

05 / 细节

水膜与湿度记忆

状态累积 / 指数衰减 / 材质映射

分别记录短暂表面水膜与较慢消退的湿度，再映射颜色和反光。

关键参数
补水、排水、干燥速率、干湿材质
可见效果
湿沙反光、暗色退水痕、湿岩石、逐渐变干。
可复用到
雨后地面、脚印、水渍；更换触发源与基底材质。
查看原库分工、教学边界与观察方法

原库：C / S：均区分快水膜与慢湿度，保留退水后的历史。

教学：④ 湿润：两个 0–1 的无量纲状态场

边界：湿润着色不会让积水流向低处，也不计算材质内部渗流。

观察：只加快干燥，水膜应保持一致，暗湿痕应更快消退。

06 / 成像

水面反射与折射

法线 / Fresnel-Schlick / Snell

用法线和观察方向分配反射与透射，再沿折射方向取水下颜色。

关键参数
相机角度、表面法线、折射率、粗糙度、环境光
可见效果
掠射时反光增强、倒影、透见水底、闪光与波纹。
可复用到
水池、湖泊；玻璃可借鉴，但须更换几何与介质模型。
查看原库分工、教学边界与观察方法

原库：C / S：水面光学与真实渲染环境相连；角度是输入条件。

教学：⑤ 光学：反射比例、折射角与光线示意

边界：教学版没有完整反射场景；多次反射、全反射需另行处理。

观察：水深不变，把角度调至接近水面，观察反射比例增大。

07 / 成像

吸收与水下体积

Beer–Lambert / 局部光线步进

按水中光程累计各颜色的衰减；局部气泡与浑浊可用体积密度表达。

关键参数
光程、RGB 吸收系数、密度场、步进数
可见效果
深水颜色变化、水下朦胧、局部气泡云与能见度变化。
可复用到
潜水、水下镜头；雾效可借鉴积分，但须补充散射。
查看原库分工、教学边界与观察方法

原库：C：水深相关吸收；S：增加水下光学与局部体积气泡效果。

教学：⑤ 光学：均匀介质 40 段透光率积分

边界：步进的是局部体积，不是整个海面；教学版不含多次散射或真实焦散。

观察：固定角度增加深度，再固定深度增加吸收，辨认光程与材质的差别。

08 / 成像

噪声与三向投影

Value noise / fBm / 法线权重

叠加不同尺度噪声产生纹理，按法线混合三个方向的平面采样。

关键参数
频率、层数、混合锐度、坐标空间
可见效果
岩石颗粒、沙纹、多尺度细节，减少单平面侧向拉伸。
可复用到
岩石、悬崖、洞穴、地形；连接湿度可形成湿岩石。
查看原库分工、教学边界与观察方法

原库：C：程序噪声与三向材质；S：另有摄影岩石素材与湿度系统。

教学：⑦ 材质：球体上的噪声与投影权重

边界：纹理不是几何；轮廓、碰撞体、水力地形仍需独立制作。

观察：切换 RGB 权重，再撤掉三向混合，观察侧面拉伸与过渡。

07 / PRODUCT DIRECTIONS

从研究资产，到可以开发的产品。

以下是产品化建议。每个方向说明现有基础与待补能力，不把规划当成已实现功能。

图形学交互课程

面向自学者、课程与技术团队

已有基础：已有七组 A/B 实验、原理说明、引导任务与数值检查。

需要补齐：补充课程顺序、练习判定、学习进度和实验记录管理。

把看到效果变成能够解释、预测和验证效果的学习过程。

水效果参数与素材编辑器

面向前端三维开发者与技术美术

已有基础：已有参数范围、固定种子、对照机制和材质映射实验。

需要补齐：接入真实 GPU 材质、预设库、统一模块接口、参数导出与视觉回归。

更快找到目标水感，并把验证过的配置带到自己的场景。

沉浸海岸互动展厅

面向文旅展示、品牌体验与景观展示

08 / REUSE & VALIDATE

要复用，先判断改到哪一层。

这是开发方向与工作量的判断方法，不是原库已实现功能清单。

01

调参数

已有行为中的变化

波更高、纹理更细、地面更快干、反光更强。

保持模型不变，固定其他输入，做 A/B 验证。
02

适配场景

换输入与约束

海岸换沟渠；湿沙换石板；雨滴触发湿度。

同步修改地形、边界、坐标、比例尺与材质。
03

连接模块

让不同能力协作

泡沫读取浅水流速；浪唇冲击注入浅水；湿度驱动岩石材质。

定义数据接口、单位、时序与水量 / 动量交换。
04

新增模型

超出现有表达范围

船体浮力、倒水与三维破碎、泥沙侵蚀、真实渗流。

增加相应物理与几何表达，配套新的验证；并非只改参数。

一条可复现的验证路径

  1. 固定条件：同一时间、随机种子、相机、单位和颜色尺度，一次改变一个原因。
  2. 核对局部：检查水量收支、非负水深、解析吸收、半衰期、弹道与权重，结合图像观察。
  3. 连接后再查：核对水花、白沫、湿痕与地形是否对齐，特别检查边界、落水时刻和切换视角。
  4. 测整体成本：另做加载、帧时间、内存、手机和长时间运行验证；工程用途还需实测校准。

已有教学验证：24 个检查，默认 / 最小 / 最大参数共 72 个局部断言，加上浅水长时间运行，合计八个测试组。它们验证本教学实现，不证明原库物理精度或最终视觉真实性。
