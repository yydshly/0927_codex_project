## 五项摘要

**呈现效果：**把海岸水面拆成七组可调的 A/B 教学画面，配合实时数值、历史曲线和总图解释变化原因；原库真实效果另设研究页。

**内部模块：**波浪、浅水、输运、湿度、光学、翻卷与喷溅、噪声与三向投影；配套八个场景入口、参数与时间管理、24 项局部检查、链接和记录导出。

**使用场景：**水面算法学习、参数对照、效果原型验证、海岸与湖池及雨后地面等场景的模块选型与复用评估。

**可扩展产品方向：**图形学交互课程、水效果参数与素材编辑器、沉浸海岸展示、场景视觉预演工具；需继续接入课程管理、GPU 材质、模块接口和设备适配。

**对我的意义：**建立从场景目标到算法组合、参数验证和模块复用的判断方法，区分调参数、适配场景、连接模块与新增模型，沉淀自己的三维交互知识资产。

## 七组实验

| 实验 | 核心模型 | 主要可验证关系 |
| --- | --- | --- |
| 波浪合成 | 解析模型 / 频域计算 | 固定 IFFT、频谱和种子后，B 的 RMS 应为 A 的 2 倍。 |
| 浅水流动 | 数值计算 / 高度场 | B 的裸露障碍更大，水流绕行；两侧仍应分别满足水量收支。初始地形不同，不能直接比较总水量大小。 |
| 泡沫与纹理输运 | 半拉格朗日平流 / 插值 | B 的浓度和总量会比 A 更快降低；速度场保持相同，运动路径应相近。 |
| 湿润与干燥 | 状态累积 / 指数衰减 | 两侧的水膜均值一致；B 的湿度下降更快。水膜排水和吸收湿度是独立参数。 |
| 水体光学 | Schlick 近似 / 吸收 / 体积积分 | B 的反射率明显高于 A。水深不变，折射后的水内光程也会略有变化。 |
| 翻卷与喷溅 | 参数化水幕 / 弹道粒子 | B 的浪唇更早落水、前伸距离更短。验证面板会检查预计落水时刻的高度接近零。 |
| 噪声与三向投影 | Value noise / fBm / 三平面映射 | B 的侧面纹理拉伸更明显。这个实验验证的是视觉表现，权重检查只能验证混合计算。 |

## 八个场景目标

- **开阔海面**：建议组合 波浪合成 + 水体光学 + 泡沫与纹理输运。先合成波形，再接水体光学。这里观察波的尺度、方向和叠加，不处理海岸破浪。
- **湖泊与泳池**：建议组合 水体光学 + 波浪合成 + 湿润与干燥。平静水面可先复用光学与轻微波动；封闭岸线、物体扰动和池壁需要另外接入。
- **浅溪与沟渠**：建议组合 浅水流动 + 泡沫与纹理输运 + 水体光学。实验使用沟渠岸坡与凸起障碍。水只能按地形高度移动，不能穿越实体高点；入口和出口需按真实场景设计。
- **雨后地面**：建议组合 湿润与干燥 + 噪声与三向投影 + 水体光学。用快消退的水膜与慢消退的湿度控制颜色和粗糙度。本实验不计算雨滴撞击或地面积水流动。
- **水下观察**：建议组合 水体光学 + 泡沫与纹理输运。加深水层、提高浑浊度，观察透光衰减。局部气泡云可用体积步进扩展；本实验先验证均匀介质。
- **冲浪与水幕**：建议组合 翻卷与喷溅 + 浅水流动 + 泡沫与纹理输运 + 水体光学。浪唇几何、弹道、水体冲击需要共同的时刻和位置。本实验只拆解浪唇运动与粒子，未连接完整浅水系统。
- **溪流泡沫**：建议组合 泡沫与纹理输运 + 浅水流动 + 水体光学。白色示踪物随给定速度场移动。它不会反过来推动水；染色、泡沫、漂浮纹理可以借用这一层。
- **岩石与悬崖**：建议组合 噪声与三向投影 + 湿润与干燥。用噪声生成多尺度纹理，按表面方向混合三向投影。几何轮廓、碰撞体和水力地形仍要另外制作。

场景入口表示复用目标和推荐组合；每次运行的是一层独立算法，不是八套已经耦合完成的写实场景。

## 怎样做一次实验

1. 选择场景，再选择要理解的算法层。
2. 用“应用这个实验”恢复标准参考，只改变一个参数。
3. 观察 A/B 相同时间下的画面、指标和历史曲线。
4. 暂停、重播或单步；必要时把当前 B 设为新的参考 A。
5. 运行当前算法检查，核对解析解或不变量；改变参数后检查会失效，需重跑。
6. 复制参数链接或导出 JSON 记录，保留配置、指标、曲线和检查结果。

修改参数会把两侧同时重置到 0 秒。链接保存场景、算法、种子和 A/B 参数，重新打开从 0 秒开始；不保存播放进度或手动扰动。初始波浪示例 A 振幅为 0.24 m、B 为 0.36 m，便于初次观察。

## 模型说明与迁移边界

### 01 · 波浪合成

相同的海面目标可以由少数波直接相加，也可以先分配各频率的能量，再用二维逆 FFT 生成高度场。

- **输入：**频率、方向、振幅、种子、时间
- **状态：**32 × 32 高度场
- **计算：**IFFT 路径使用共轭对称频谱，确保结果为实数；按深水色散关系推进相位。另一路直接叠加四个余弦波。
- **观察：**先把 B 的振幅加倍，观察 RMS；再增大主要频率，观察波峰数量。别用单帧峰谷差代替整体波能量。
- **复用：**湖泊、海洋背景和景观水池可从这一层起步。改波形通常调参数；接岸线、障碍或船体需要新的耦合。
- **边界：**这是独立的 Gaussian 方向教学谱，不是 ShoreBreak 的完整 JONSWAP、三层级联或原站画质。没有岸线、冲击、倒卷水幕。

[coastal · 解析波输入](https://github.com/iamtechartist/coastal-simulation/blob/2e95e1a3e757ca1268247417dee01606e5e3d55c/src/coast.js) · [ShoreBreak · 风浪与其他模块的分工](https://github.com/cryptomanavan/ShoreBreak/blob/11c8c057db671628ef2dbc308ab9fe0f233f48dc/docs/ARCHITECTURE.md)

### 02 · 浅水流动

每个格子保存水深，相邻水面高度差推动水平流速。搬运的是水量，所以可以核对流动前后是否守恒。

- **输入：**海床高度、水位、边界驱动、阻尼
- **状态：**48 × 28 水深 + 面流速
- **计算：**压力梯度推动格子面上的速度，用上游水深计算通量，再限制总流出量，避免出现负水深。步长根据当前速度和水深自动细分。
- **观察：**灰褐色是裸露地形。水面偏移视图中，蓝色低于初始水面，暖色高于它；水深视图用青蓝色表示深浅。关闭边界驱动后，水可移动，但总量应保持不变。
- **复用：**适合浅溪、沟渠和薄层地表水的视觉原型。更换场景必须一起修改地形和边界；数值守恒通过不等于工程精度验证。
- **边界：**独立教学求解器省略非线性动量平流、湍流和侵蚀。每个水平位置只有一个水面高度；岸坡、边界和障碍是人为配置。

[coastal · 交错网格与流量限制](https://github.com/iamtechartist/coastal-simulation/blob/2e95e1a3e757ca1268247417dee01606e5e3d55c/src/simulation.js) · [ShoreBreak · GPU 有限体积求解](https://github.com/cryptomanavan/ShoreBreak/blob/11c8c057db671628ef2dbc308ab9fe0f233f48dc/src/swash/SwashSim.js)

### 03 · 泡沫与纹理输运

当前位置沿速度反向追踪，再从上一帧采样。水流由这里预设的速度场给定，白色示踪物只是被搬运的标量。

- **输入：**上一帧浓度、给定速度场、消散速率
- **状态：**64 × 40 浓度场
- **计算：**反向追踪到网格之间时，用四个邻近格子的双线性插值估算浓度。左右、上下都使用周期边界。
- **观察：**关闭消散并观察白团边缘，仍会逐渐变柔和，这是插值带来的数值耗散。复杂速度场下，总量不保证严格守恒。
- **复用：**用于水面泡沫、漂浮纹理、二维染色和污染扩散的视觉表达。真实物质守恒或三维流动要采用相应模型。
- **边界：**本实验只输运二维标量，不求解速度、不计算三维烟雾，也不让泡沫反过来改变流体。

[coastal · transport 与回溯采样](https://github.com/iamtechartist/coastal-simulation/blob/2e95e1a3e757ca1268247417dee01606e5e3d55c/src/simulation.js) · [ShoreBreak · foam 与输运](https://github.com/cryptomanavan/ShoreBreak/blob/11c8c057db671628ef2dbc308ab9fe0f233f48dc/src/swash/SwashSim.js)

### 04 · 湿润与干燥

表面水膜和吸收湿度使用不同时间尺度。水膜控制明亮反光，湿度控制深色残痕，让退水后的地面保持连续变化。

- **输入：**局部洒水或持续补水、排水与干燥速率
- **状态：**水膜 f 与湿度 w，范围 0–1
- **计算：**水膜按排水率衰减，水膜还会使湿度上升；湿度按另一速率恢复。浓度不代表真实毫米水深，颜色和高光由状态映射。
- **观察：**先看亮水膜退去，再看深色湿痕慢慢消退。点击“同一扰动”可同时向两侧再洒一次水。
- **复用：**雨后道路、湿岩石、脚印和水渍都可复用。替换触发来源与干湿材质，即可迁移到许多非海岸场景。
- **边界：**材质记忆不是浅水流动；本实验不会算积水往低处走、雨滴冲击或材质内真实渗流。

[coastal · film / wet 状态](https://github.com/iamtechartist/coastal-simulation/blob/2e95e1a3e757ca1268247417dee01606e5e3d55c/src/simulation.js) · [ShoreBreak · RockWetness](https://github.com/cryptomanavan/ShoreBreak/blob/11c8c057db671628ef2dbc308ab9fe0f233f48dc/src/beach/RockWetness.js)

### 05 · 水体光学

观察角度决定反光比例；折射改变光路；不同颜色沿光程按不同系数衰减。体积步进把路径分段，逐段累计透光率。

- **输入：**角度、深度、折射率、吸收系数
- **状态：**反射率、折射角、RGB 透过率
- **计算：**Schlick 近似计算菲涅耳反射，Snell 定律计算折射角，Beer–Lambert 衰减计算各颜色的透过率。画面中的亮纹仅是示意材质。
- **观察：**彩色条是实际算出的 RGB 透过率；光线箭头表达角度关系。增加水深与改变角度是两种不同原因。
- **复用：**湖泊、泳池和水下观察可复用这一组关系。玻璃与雾可借鉴公式，但要更换几何、介质和光照模型。
- **边界：**均匀介质的 40 段积分用于理解局部体积步进；不含原库完整反射贴图、真实焦散、气泡云密度或多次散射。

[coastal · Fresnel 与指数吸收](https://github.com/iamtechartist/coastal-simulation/blob/2e95e1a3e757ca1268247417dee01606e5e3d55c/src/shading.js) · [ShoreBreak · 水下体积与水面渲染的区别](https://github.com/cryptomanavan/ShoreBreak/blob/11c8c057db671628ef2dbc308ab9fe0f233f48dc/docs/ARCHITECTURE.md)

### 06 · 翻卷与喷溅

先给出浪唇的起点与速度，再按重力计算下落。连续发射的轨迹点组成教学水幕，落水后出现独立粒子。

- **输入：**发射高度、水平速度、向上速度、重力
- **状态：**水幕轨迹与独立喷溅粒子
- **计算：**水幕按一组有序轨迹采样成带状几何。首次接触水面后，按相同重力推进喷溅粒子。背景波形只是参数化外观。
- **观察：**虚线标出预测落点，亮点是浪唇前缘。每轮固定时间重播，可暂停和单步查看落水时刻。
- **复用：**适合可控冲浪镜头、水幕和效果原型。瀑布、任意倒水或船体浮力不能由这些参数直接得到。
- **边界：**独立二维剖面教学实现，不是直接运行 LipRibbon；没有水幕自碰撞、三维破碎，也未向浅水注入水量或动量。

[ShoreBreak · 独立浪唇几何](https://github.com/cryptomanavan/ShoreBreak/blob/11c8c057db671628ef2dbc308ab9fe0f233f48dc/src/water/LipRibbon.js) · [coastal · 接触喷溅](https://github.com/iamtechartist/coastal-simulation/blob/2e95e1a3e757ca1268247417dee01606e5e3d55c/src/spray.js)

### 07 · 噪声与三向投影

把多个尺度的噪声相加得到岩石纹理，再按法线方向混合来自三个平面的投影。这里使用球形载体方便检查接缝。

- **输入：**三维位置、法线、频率、层数、锐度
- **状态：**三个采样值与混合权重
- **计算：**平滑插值随机格点形成 value noise，再按半幅、倍频叠加为 fBm。三平面纹理由表面法线决定混合比例。
- **观察：**先选 RGB 方向权重，再改变混合锐度。回到材质视图，切换单平面与三平面，检查球体侧面的拉伸。
- **复用：**适合岩石、悬崖、洞穴、地形与程序化素材。与湿度模块结合可做湿岩石；几何和碰撞仍需单独制作。
- **边界：**使用独立教学噪声与规则几何，不生成真实岩石模型，不含原库摄影材质；法线和坐标空间不一致时仍会出现问题。

[coastal · 三向投影与分层噪声材质](https://github.com/iamtechartist/coastal-simulation/blob/2e95e1a3e757ca1268247417dee01606e5e3d55c/src/shading.js)


## 运行与验证

需要 Python 3.10+ 构建；Node.js 22 用于测试；浏览器支持 Canvas 2D 与 ES modules。无需安装第三方包、GPU API、服务端或 API key。

```sh
node --test projects/010-algorithm-scene-lab/web/model.test.mjs
python projects/010-algorithm-scene-lab/web/build.py
python -m http.server 4328 --bind 127.0.0.1 --directory dist
```

浏览器打开 http://127.0.0.1:4328/010-algorithm-scene-lab/ 。通过总构建访问时，所有研究页和首页相互连接。不能用 file:// 直接打开模块脚本。

数值推进固定为每步 1/30 秒，浅水内部按速度与水深细分时间步。隐藏页面时暂停推进；性能较差时模拟时间可能慢于现实时间。本项目没有做硬件帧率基准。
