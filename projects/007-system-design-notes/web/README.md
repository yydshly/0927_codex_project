# 系统设计笔记 · 中文导览网页

纯静态单页，使用原生 HTML、CSS 和 JavaScript，无第三方依赖、账号或后端。

## 使用

在仓库根目录执行：

```sh
node projects/007-system-design-notes/web/build.mjs
```

构建产物为本目录的 `dist/`，可使用静态文件服务器打开 `dist/index.html`。页面资源均为相对路径，适用于统一 GitHub Pages 的子路径。

## 页面结构

- 首屏总结定位与能力边界。
- 一张可放大的 28 章能力与场景总图：五类主题、所有章节、关注能力、典型目标，以及按产品特性选用的路径。
- “小云”目标对照表：从候选目标反查对应章节、需要收集的验证证据和仓库未覆盖的隐私主题。
- “小云”从桌面原型到多人 AI 对话服务的步骤演示：修改日活、对话轮次、峰值倍数和模型响应时间，查看粗略请求量与并发估算；阅读主链路、动作事件及逐步扩展决策。
- 28 章内容地图：按五类筛选、中文关键词搜索，点击章节查看简述与上游链接。
- 四步设计方法与五类技术机制。
- 四种使用场景、四个候选产品方向、个人价值、建议阅读路径和来源说明。

本页展示的是学习笔记可以产生的**分析效果**：把产品目标与规模假设转换成设计问题、章节入口和待验证的指标。它没有运行上游 28 章中的系统，也不提供可直接部署的限流器、消息队列或聊天后端。

章节名称来自上游目录。每章的一句话导读、分类、场景与阅读顺序是本项目整理，不代表上游仓库的原有功能或经过生产验证的方案。来源快照为 `9d83887`。

“小云”场景来自本仓库 FreeMoCap 子项目关于角色动作库和对话事件选择的设想。页面的用户量、请求次数、峰值倍数和响应时间都是演示假设，计算仅在本地浏览器完成；没有模型调用、后端接口或性能实测。
