# 图片来源

`understanding-map.svg` 为本项目原创的信息结构图，概括上游章节主题和本项目归纳的阅读方法。它不是上游原图，也不是运行效果截图。

`goal-capability-map.svg` 为本项目原创的 28 章能力与场景总图。章节名称来自上游目录；五类分组、能力概括、场景与“小云”选用路径是本项目的分析，不是上游原图。

`goal-capability-map.png` 是该总图的完整网页渲染预览，便于在不支持 SVG 的位置分享；清晰放大请使用 SVG。

`build_capability_map.py` 是该 SVG 的生成源，保持 28 个章节编号完整且不重复。

`web-preview.png` 为本项目网页在本地浏览器中截取的桌面首屏，展示实际排版，不是上游仓库的运行效果。

`xiaoyun-case-preview.png` 为“小云”场景演示区在本地浏览器中的实际截图；其中的用户量与性能数字均为演示假设。

`goal-audit-preview.png` 为“从目标反查仓库能力”对照区在本地浏览器中的实际截图；候选目标与当前判断是本项目的分析草案。
