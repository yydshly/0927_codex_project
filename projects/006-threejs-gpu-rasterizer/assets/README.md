# 图片来源

`guide.png` 是本项目用 [`render-cover.py`](render-cover.py) 与 Pillow 绘制的早期示意图，展示程序化风机和原理步骤；它不是上游 WebGPU 示例截图，也不代表实测画质或速度。当前项目引导图改用下述矢量总图。三维交互画面请运行 [`../web/`](../web/README.md)。

`understanding-map.svg` 是本项目自制的中文矢量理解总图。图中的 three.js 能力来自[官方基础说明](https://threejs.org/manual/pages/fundamentals.html)与[示例库](https://threejs.org/examples/)；GPU 渲染流程根据 [PR #33605](https://github.com/mrdoob/three.js/pull/33605) 和[现版示例源码](https://github.com/mrdoob/three.js/blob/dev/examples/webgpu_compute_rasterizer.html)整理。适用场景与“对你的意义”是本项目的产品分析，并非性能实测结论。
