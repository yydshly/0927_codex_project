# Three.js 能力导览与海上风电场巡检演示

本页先以[一张可放大的矢量总图](../assets/understanding-map.svg)说明 three.js 源码库、官方示例和 PR #33605 的关系，再展示模型加载、交互、动画、画面效果、大量对象与沉浸式体验的官方参考入口，以及这些能力对三维业务产品的价值。随后通过一个可旋转、可缩放的 144 台风机模拟场景，解释为何全场概览可用较少细节，靠近告警设备时再恢复结构。演示**使用 Three.js WebGL 渲染器和 CPU 端的可见性/LOD 决策**。原 PR 的 WebGPU 计算着色器与软硬件混合光栅化见[上游示例](https://threejs.org/examples/webgpu_compute_rasterizer.html)。

## 运行

需要 Node.js 20+。在本目录运行：

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:4316/`。`npm run build` 输出可放在任意静态站点子路径下的 `dist/`。`npm run check` 进行语法检查和绘制策略计算测试。three.js 版本固定为 0.186.1，构建时把运行需要的模块和 MIT 许可证复制到 `dist/vendor/`；页面不依赖在线 three.js CDN。

## 怎么操作

1. 打开“理解总图”并放大阅读全貌，再从页面“Three.js 能力”部分进入相关官方示例观察效果。
2. 在全场俯瞰视角轮流选择“全部高精度”“只做视野筛选”“按需选精度”，看几何提交估算。
3. 点击“定位 W-087”，进入模拟告警设备的近景；在按需模式下观察可见数量和几何量变化。
4. 调整“可接受的屏幕误差”，观察省略细节的幅度。
5. 拖动场景旋转、滚轮缩放或直接点击风机，查看选中设备。所有设备状态为模拟值。

## 指标解释

- **本帧绘制风机**：本演示实际提交到 `InstancedMesh` 的风机实例数量。
- **几何提交估算**：各精度模型的三角形数乘对应实例数之和。
- **相对全部高精度**：与 `144 × 高精度模型三角形数` 的差额百分比。

这些数字**不等于帧率、GPU 时间或原 PR 的实测性能**。比较是为了看清筛选与选精度对几何工作量的影响。本页风机是程序化模型，巡检告警、海域名称和设备状态均为模拟内容，不用于实际运营。
