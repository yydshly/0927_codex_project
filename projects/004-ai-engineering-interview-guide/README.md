## 核心结论

这是一个以 Markdown 文档为载体的 **AI 工程面试知识索引与题库**。它组织了通用知识、公司专项题、岗位与面试流程概况，以及部分外部答案链接，帮助使用者确定复习范围并练习技术表达。

这里的“能力”指资料的组织与学习支持能力。上游没有提供可安装的 AI 框架、模型服务、自动出题或自动评分应用。本次完成的是内容盘点与研究汇总。

## 四个问题，一条使用路径

| 问题 | 我们的理解 |
| --- | --- |
| 这个库的能力是什么？ | 它把公开面试经历中的问题按技术主题和公司组织成索引，帮助确定复习范围、练习技术解释与工程取舍；部分题目链接外部资料。 |
| 内容有哪些？ | 固定版本收录 598 道题：10 个通用模块、119 道通用题，以及 35 个公司或分组章节、479 道专项题。232 道题附外部参考链接；本子项目网页另为 45 道重点题整理中文题意与答题要点。 |
| 适合什么时候用？ | 目标公司求职、转向 AI 工程、检查现有项目的设计与故障处理、同伴模拟面试、团队讨论。 |
| 对我有什么意义？ | 把岗位要求转成可选的题目清单；通过先自答、再查证、动手实现与复盘，找到薄弱项并留下代码、设计和评测记录。 |

建议先选岗位和方向，再做相关通用题与公司专项题。把答不清的问题转成具体学习任务，把可实现的问题转成小实验。完整路线见[使用指南](notes/usage-guide.md)，可放大阅读的[完整引导图](assets/ai-engineering-guide-map.png)汇总了各模块细节。

## 提供的能力

| 能力 | 实现方式 | 使用价值 |
| --- | --- | --- |
| 按公司定位材料 | 岗位、流程概况、专项题与通用题关联 | 围绕目标岗位缩小准备范围 |
| 按主题查漏补缺 | 十类通用问题及部分公司标签 | 发现薄弱知识点，组织学习清单 |

## 使用边界

- **面试来源未逐条核验。** 作者称信息来自公开经历；轮次与要求随团队、级别、地区变化，应结合实际招聘信息。
- **答案尚不完整。** 366 条未附答案链接；已有文章也可能只解释背景，未覆盖题目全部要求。
- **工程题需要自行实现。** 题干要求实现组件，不等于仓库附带可运行项目和测试环境。
- **需要自己安排学习。** 没有统一难度分级、先修关系、学习时长和掌握标准。
- **外链需分别判断。** 本次未逐条核验外部答案的正确性、可访问性和使用条件；仓库许可证不自动覆盖外部内容。
