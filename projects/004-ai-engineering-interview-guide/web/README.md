## 页面内容

- 仓库定位：说明资料能支持的学习与备考活动，并展示研究快照的内容规模。
- 题目与答案：网页内收录固定提交中的全部 598 道原题（通用 119、公司专项 479），可按范围、主题或公司、关键词和答案状态筛选，分批浏览。展开题目可阅读原题、45 道本站中文答题要点、232 道题对应的 310 个仓库答案参考链接及原题出处。没有参考链接的题目明确标注。
- 模块导读：10 个模块按“理解模型、构建应用、走向生产”分组。点击卡片可查看该模块全部通用原题与答案入口，再读知识点、阅读步骤、先备知识和学习目标。
- 岗位路线：AI 应用开发、推理与平台、研究与后训练、客户交付与方案四个方向。路线步骤可以打开对应模块。
- 公司目录：5 类组织、35 个公司或公司分组章节，展示专项题数量、答案链接数量及主题范围。点击公司会在本页筛选对应原题，并展示上游整理的岗位和面试流程信息。
- 来源与边界：说明答案覆盖、信息时效、统计口径和许可来源。

中文导读、三组能力分类与岗位路线为本项目整理；不是上游仓库自带的软件功能或官方招聘标准。

## 本地启动与构建

需要 Node.js 20 或更新版本，无需安装第三方依赖。在本目录运行：

```sh
npm run dev
```

默认预览地址为 [http://127.0.0.1:4304](http://127.0.0.1:4304)，只监听本机。可通过环境变量 PORT 更换端口。启动时先生成静态文件；修改源文件后运行构建并刷新页面。

```sh
npm run build
```

构建产物为本目录的 dist/。构建读取 ../data/source-summary.json、../data/questions.json 与 ../data/answer-notes.json，生成浏览器可直接加载的数据文件；内容来自固定快照，没有实时抓取或模拟数据。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| index.html | 页面结构、定位说明、来源与边界 |
| styles.css | 桌面与移动布局、主题和交互样式 |
| content.js | 模块导读、分类、岗位路线和主题译名 |
| app.js | 题目搜索筛选、答案展示、模块弹窗、路线切换与公司分组 |
| scripts/build.mjs | 生成独立静态产物，复制来源许可证 |
| scripts/serve.mjs | 本地预览与子路径验证 |

页面不需要密钥、账号或后端，也不会提交用户输入。没有加入学习进度保存、自动评分或在线模拟面试。

上游 README 主要提供题目与外部参考链接，并未内嵌 598 道题的完整答案。本站中文答题要点由本项目独立整理，和上游参考链接分别标注；外部资料正文没有转载进网页。
