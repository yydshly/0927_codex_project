# 西安夜行图 · Web 0.3

全屏三维末班车图谱与返程产品原型。Node.js 20+，支持 WebGL 2 的浏览器。

## 启动与构建

```sh
npm ci
npm run dev
```

打开 http://localhost:4175/ 。预览仅监听本机。修改源文件后刷新页面。可用 `PORT` 环境变量更改端口。

```sh
npm test
npm run build
```

`dist/` 可通过静态 HTTP 服务独立运行，支持子目录路径。安装时需要网络；运行时所有依赖、图标及地理快照均为本地资源，无 API 密钥。请不要直接以 file:// 打开。仓库将本项目纳入 GitHub Pages 统一发布，公开页面为 <https://yydshly.github.io/0927_codex_project/001-xian-night-atlas/>；以远端实际可访问状态为准。

## 文件与依赖

| 文件 | 用途 |
| --- | --- |

| `src/app.js` | 界面状态、搜索、场景和返程联动 |
| `scripts/prepare.mjs` | 将锁定版本的 Three.js 与 Lucide 复制到本地静态目录 |
| `scripts/build.mjs` | 构建相对路径的静态产物 |

## 数据约定

- 当前仅演示精选线路与站点，不是完整线网。空中轨道连接为视觉插值，地面地理位置来自 OSM。
- 发车及区间时长均为模拟值。以末班为基准、每 8 分钟构造此前班次；同车连续乘坐不重复候车。
- 换线或换方向预留 6 分钟；最晚出发使用可达性二分查找并扣除步行。
- 周末统一延后 12 分钟，属于演示规则。
- 服务日分钟数跨午夜不清零；1500 表示次日 01:00。
- 时间高度按两个方向在每个站的末班经过时刻分别抬升；分层视角按线路分层；平面视角同时降低轨道并切换俯视镜头。
- 时间推进使已通过区间逐渐熄灭。列表表示是否仍有站点可发车，不能单独推断某段返程还能完成。
- 夜游的计划离开时刻为当前模拟时刻加停留；建议离开时刻为最晚可行时刻减 10 分钟，缓冲不额外计入乘车用时。
- 可达范围使用一次多目的地最早到达搜索，缓存到模拟分钟。时间上限从离开地点算起，包含步行到站、候车与换乘，不含停留和出站后步行。
- 可达数量排除起点；只描绘 71 个样本站的站点和有效有向区段，不生成连续地理等时圈。
- 再逛 30 分钟的比较可能出现新增站点：候车周期会改变是否符合用时上限。因此分别计算减少及新增，不假定数量单调递减。
- 保存键为 `xian-night-atlas:plan:v1`，仅在点击保存时写入 localStorage。读取时校验站点、时间范围、日期类型及预算，拒绝损坏数据；没有网络同步或通知。

## 复验场景

1. 工作日 22:30，钟楼 → 西安北站，步行 8 分钟：总计 37 分钟，23:07 到达，最晚 23:18 出发。
2. 大雁塔散场：22:30、步行 15 分钟，4 号线在五路口换 1 号线，23:38 到达后卫寨，最晚 22:35 出发。
3. 高新加班：23:15 默认场景错过衔接，提示最晚 22:56；可点击回到建议时刻 22:46，停留重置为 0。
4. 搜索、排序、线路／车站详情、设为起终点、交换、相同起终点、空结果。
5. 时间拖至 01:30 全线末班已过；测试播放、暂停、1×／4×、重置、工作日／周末。
6. 三种视角、旋转、缩放、复位、日夜切换；手机抽屉与时间控制。
7. 钟楼 22:30、步行 8 分钟：30 分钟预算有 23 站，45 分钟有 55 站，60 分钟有 68 站；45 分钟预算下再逛 30 分钟有 27 站。
8. 大雁塔北广场预设、去西安北站：继续停留 90 分钟后无法返程，到站显示次日 00:15；回到建议 22:37 后显示 70 分钟、23:47 到达。
9. 可达列表选择目的地进入返程；保存后刷新恢复预设、起终点、停留、时间、预算与模式；01:30 范围为空且显示原因。

详细截图与验收记录见 ../design-qa.md。真实运营应用仍需完整线网、逐车时刻、节假日调整和更新机制。
