## 五项视觉检查

| 范畴 | 结论 |
| --- | --- |
| 字体与层级 | 中文城市标题、英文副标题、线路编号、末班大数字、站名与英文分层；地图标签保持正面朝向；使用本地系统字体，无远端字体依赖 |
| 间距与布局 | 延续原站的左上品牌、左侧线路、右上视角、底部时间轴结构；返程与详情按需展示；三种验收尺寸均无页面横向溢出 |
| 色彩与状态 | 深蓝夜景、浅色日景、线路色、末班已过的暗线、行程高亮和白色列车光点分离；控件有明确的选中、焦点和空结果状态 |
| 图形与资产 | 真实三维几何及 OSM 地理快照；无假三维 CSS 倾斜。图标使用 Lucide，引用本地 SVG；版权信息留存在构建中 |
| 文案与内容 | 全界面使用西安语境；持续标注“模拟时刻”，说明精选站点、轨道插值与周末偏移。没有声称实时、官方或完整全网 |

与原站的有意差异：原站为东京 76 条线路／940 个车站；本项目为西安 6 条线路／71 个关键站点，因此线网密度不同。增加实际城市底图、双向末班返程计算、场景切换与日夜双主题。地图保留更大的底图空间来表达真实地理关系。

## 实际交互检查

- 鼠标拖动旋转，镜头视角实际变化，站名保持朝向；缩放、复位与三种视角控制可用。
- 车站详情可查看双向末班，并设为起点或终点；选中后镜头聚焦。
- 搜索“钟楼”正确返回两条换乘线路；无匹配名称显示明确空结果；“最晚结束”排序将 6 号线置顶。
- 工作日／周末改变列表与返程时刻，周末演示偏移为 12 分钟，跨午夜显示 00:xx。
- 时间滑块可键盘推至 End：01:30，显示今夜末班已全部驶过；重置回 22:30。
- 播放后观察到时间推进，暂停停止，速度按钮提供 1×／4×。
- 钟楼 → 西安北站：步行 8 分钟，总计 37 分钟，23:07 到达，最晚 23:18 出发。
- 大雁塔 → 后卫寨：步行 15 分钟，五路口换乘，总计 68 分钟，23:38 到达，最晚 22:35 出发。
- 高新加班默认时间：正确进入错过衔接状态，提供回到 22:56 的操作。
- 手机打开／收起面板、切换返程、提交后滚动到完整结果；底部时间控制一直可用。
- 说明弹窗可打开／关闭；原生 dialog 提供焦点管理，控件具备语义名称与键盘焦点样式。减少动态效果偏好会关闭插值。

- `npm test`：15 项全部通过（原 7 项，加 8 项规划测试）。覆盖一次多目的地搜索与逐站搜索一致性、步行与停留只计一次、10 分钟缓冲、预算包含候车与换乘、起点排除、有效方向区段、增减目的地集合、午夜空结果、保存内容校验和地点映射。
- `npm run build`：成功生成 Web 0.3 静态产物；本机 `/`、`/dist/`、构建后的规划模块、场景模块与样式可通过 HTTP 读取。
- 工作日钟楼 22:30、步行 8 分钟：30 / 45 / 60 分钟预算分别为 23 / 55 / 68 个目的站。45 分钟预算下再逛 30 分钟变为 27 个，减少 28 个。
