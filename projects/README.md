# 子项目目录

完整项目列表和图片见[仓库首页](../README.md#项目索引)。此目录仅收录实际研究项目；模板保存在 [`templates/project`](../templates/project/)。

- 目录按 `001-project-name`、`002-project-name` 命名，编号永久保留。
- 每个项目的 `project.json` 维护索引元数据；首页由脚本生成。
- 项目详情、研究笔记、截图和演示源码存放在各自目录内。
- 已归档项目仍保留目录和编号，避免旧链接失效或编号复用。

新增方法见[维护约定](../docs/CONVENTIONS.md)。
