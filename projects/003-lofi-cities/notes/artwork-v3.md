# 场景原画与生成记录

2026-09-27 使用内置 ImageGen，逐场景生成六幅独立位图；没有使用 CLI，也没有把原站截图作为产品素材。原图保留在生成目录，产品版本位于 `web/assets/scenes/*-v3.png`。画面是精细插画，天气、光晕、水面和窗外流光由程序叠加，并非完整角色动画或分层视频。
