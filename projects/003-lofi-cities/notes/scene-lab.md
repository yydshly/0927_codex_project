# 雨夜书房：用另一个场景理解 Lofi Cities

日期：2026-09-26。范围：桌面网页。入口：[本地场景实验](http://127.0.0.1:4313/research.html#lab)。

## 先回答“是不是图片加音乐”

从感官上看，是一个画面加声音；从实现上看，原站的公开脚本显示它把场景绘制、时间变化、音频合成与参数控制组织成了一个可运行的系统。

- [engine/core.js](https://loficities.com/js/engine/core.js)：480×270 逻辑画布、像素绘制工具和时间计算。
- [scenes/istanbul.js](https://loficities.com/js/scenes/istanbul.js)：由代码绘制建筑和前景，缓存静态层，按时间绘制水面、船只、鸟等；还定义场景音效事件。
- [audio/engine.js](https://loficities.com/js/audio/engine.js)：编曲、节奏、旋律与乐器合成的调度。
- [audio/sounds.js](https://loficities.com/js/audio/sounds.js)：使用振荡器、噪声和滤波器等构造环境声音。
- [music/playlist.js](https://loficities.com/music/playlist.js)：读取时播放列表为空，预留录制音轨接入方式。不能把“当前采用合成”概括为永远不支持音频文件。

这些依据来自线上可公开读取的脚本；未确认独立开源仓库、许可证或可安装的 SDK。读取实现与获得工程复用授权是不同问题。

## 这次换成什么

以原创“雨夜书房”为实例：冷色夜城与窗雨、暖色台灯、书架、书本和杯中蒸汽。全部画面由本项目代码绘制，声音也由本项目合成；没有复制原站代码、图片、音乐或场景内容。

目标是让关键关系可以操作、可以观察，而不是重建完整原站引擎。

| 部分 | 本例实现 | 可观察的行为 |
| --- | --- | --- |
| 静态空间 | Canvas 绘制房间与建筑，缓存底图，每帧叠加窗框与桌面 | 对比纯底图，房间仍然完整 |
| 时间变化 | 确定性雨滴位置、蒸汽摆动、灯光轻微起伏 | 暂停画面，画面时间停止 |
| 环境声 | 生成噪声缓冲，循环播放并经过高低通滤波 | 音乐音量设为 0，可单独体验雨声 |
| 音乐 | 四组和弦，振荡器生成轻柔分解音与低音，包络控制起落 | 调 BPM 改变下一批音符节奏；和弦读数持续切换 |
| 混音 | 音乐与雨声各自的增益，合并后经过压缩和信号分析 | 音量独立可调，信号表来自实际音频数据 |
| 参数联动 | 雨量控制粒子数及雨声强度 | 雨量从 0 到 100，雨滴从 0 到 150，雨声随之增强 |
| 生命周期 | 动画帧与音频时钟分离，离开栏目时暂停声音与绘制 | 暂停画面不停止音乐；离开实验页会停声 |

## 推荐的三个实验

1. 点击“对比纯底图”，再恢复完整场景。观察雨滴、光照和蒸汽增加了什么，而不是只关注像素画本身。
2. 点击“开启声音”，再“暂停画面”。观察画面时间停止，和弦读数与实际信号继续改变。两套系统各有时钟，可以共享参数，不必绑定成视频。
3. 把雨量从 0 调到 100，再取消“雨滴”图层。前者联动视觉和听觉，后者只影响视觉。这也是参数接口与渲染开关的差别。

## 模块关系

```text
控制面板 → 同一份参数
              ├─ 画面时钟 → 缓存底图 + 动态层 + 前景 → Canvas
              └─ 音频时钟 → 音符 / 噪声 → 独立音量 → 合并 → 输出
```

- `lab-model.js`：参数范围、种子随机、雨滴位置、和弦与 MIDI 音高换算。
- `lab-scene.js`：绘制空间和动态层。雨滴裁剪到窗户内，窗框绘制在雨滴上方。
- `lab-audio.js`：按音频时钟提前安排音符；参数变化平滑调整增益，避免突变。恢复后跳过错过的时间，避免补播积压音符。
- `lab.js`：连接控件和模块；尊重减少动画偏好，默认静音；退出栏目暂停，返回后由用户重新开启声音。

示例雨声是过滤后的循环噪声床，音乐是四组固定和弦的简化循环，不等于原站完整程序化编曲。没有引入 AI 模型。

## 从这个例子得到的产品判断

**可复用的是运行机制，场景内容仍需要制作。** 换成森林木屋时，可以复用参数、绘制循环和混音，只替换树林、萤火虫和虫鸣规则；换成深夜列车时，需制作车厢、窗外移动景物、轮轨声及相关事件。

可以逐步形成三类资产：

1. 引擎能力：加载、暂停、切换、音频调度、混音、输出与清理。
2. 场景配方：空间构图、色彩、动态元素、声音设计和参数范围。
3. 用户配置：写作、阅读、放松的整套参数，支持保存与恢复。

因此，最直接的扩展是“可保存的个人环境”和“可嵌入的场景组件”。场景编辑器需要进一步抽象绘制与声音规则，不能由增加几张图片自动获得。

## 验证与边界

数据检查覆盖参数范围、零雨量、最大粒子数、长时间坐标边界、可重现性和标准音高；浏览器交互结果记录在 [research.md](research.md)。

本例无后端、无外部媒体依赖。未完成主观音质评价、长期后台连续播放、系统休眠恢复、性能压测和跨浏览器专项测试。
