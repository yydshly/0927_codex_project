# 栖间 · 桌面氛围应用

主入口 `index.html` 为完整应用；`research.html` 保留原研究与单场景实验。无第三方运行时依赖。

## 启动

Python 3.10+，测试使用 Node.js 18+。在本目录执行：

```sh
python -m http.server 4313 --bind 127.0.0.1
```

[打开产品](http://127.0.0.1:4313/#space)。

- `#space`：全窗口动态场景、六套一键氛围组合与常驻播放器。
- `#settings`：场景旁的环境控制抽屉。
- `#explore`：六场景、动态预览、分类及预览暂停。
- `#music`：六种背景音乐与本地音频。
- `#compare`：双场景对比。
- `#library`：收藏与命名环境。
- `#focus`：计时、记录和睡眠定时。
- `#understanding`：产品理解、意图示例、能力边界与扩展路线。

研究页面使用 `research.html#overview`、`research.html#lab` 等原栏目。

## 数据与边界

- 产品数据：`quiet-spaces-v1`；计时：`quiet-spaces-v1-timer`。旧演示继续使用自己的键。
- 音频必须经用户操作启动；刷新后恢复设置但不自动播放。
- 栏目切换不断音乐；空间、对比、探索、收藏按需绘制；仅动画可见卡片，隐藏页面停止画面调度。
- 场景运动与天气各有开关和速度/强度控制；新增配置可随命名环境保存。
- 开发验收页 `tests/motion-check.html` 验证六场景实际像素运动、暂停与独立开关，不进入发布构建。
- 计时使用实际截止时间，刷新可恢复；每段完成后等待用户开始下一段。
- 场景比较不混合两路音乐，继续播放主空间的声音。
- 本地音频在浏览器内解码，不会上传；不保存音频文件，刷新后重新选择，单文件最多 60 MB。
- 产品无外部媒体请求、后端、云同步、账号或离线安装。清除浏览器存储会删除本地数据。
- 原研究截图仍为静态图；产品以本地场景插画为底图，再绘制可控的动态叠层。

完整功能、操作约定与验证范围见 [产品说明](../notes/product.md)。

## 3.0 成品交付

主空间成为铺满窗口的动态画面；场景、音乐、收藏、专注、对比以面板打开，环境调节在右侧抽屉完成。底部播放器常驻。纯画面模式隐藏导航与播放器，鼠标移入画面可退出，Esc 也可返回。

六套一键组合分别为雨夜阅读、林间放松、海岸午后、深夜远行、城市心流、雪夜放空。点击组合会切换场景、合成音乐、环境声、动态与天气，并启动播放。保留用户总音量和画面暂停偏好；手动改动后显示“我的专属搭配”。新用户默认使用雨夜阅读，已有用户的设置、收藏及记录继续保留。

生成可部署的独立成品包：

```sh
python build.py --package
```

根目录 `dist/quiet-spaces-3.1.0.zip` 只包含产品入口、运行代码、场景素材和使用说明；研究页面与测试工具不包含在内。保持目录结构部署到 HTTP(S) 静态托管即可，无需依赖安装或后端。当前仅完成本地交付，没有发布到公共域名。
