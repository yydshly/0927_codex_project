HOW THE ROOM WORKS

一个空间，四个可以复用的部分。

01 / 构图

底图提供空间

房间、书架与远处建筑先画到缓存。每一帧重复使用，再补上窗框和桌面，形成前后关系。

Canvas → 缓存底图 → 前景
02 / 动画

时间让空间活起来

雨滴位置随时间变化；蒸汽摆动、灯光轻微起伏。暂停的是画面的时间，并非一段视频。

位置 = 初始位置 + 速度 × 时间
03 / 声音

浏览器现场生成

噪声经过滤波成为雨声；振荡器按音高与和弦发声。声音使用自己的时钟，分别调节后混合。

噪声 / 音符 → 音量 → 输出
04 / 联动

参数连接各个部分

雨量同时影响画面和雨声；BPM 只影响音乐。替换绘制规则与声音配方，就能扩展到新场景。

同一组参数 → 画面 + 声音

TRY THREE SMALL EXPERIMENTS

这样操作，更容易理解。

① 对比纯底图

雨滴、蒸汽和灯光消失，书房仍然完整。构图负责场所感，动态层增加“这里正在发生什么”的感觉。

② 开启声音，再暂停画面

画面时间停住，和弦与信号仍在变化。两套系统各自运行，不需要把声音烘焙到视频里。

③ 把雨量从 0 拉到 100

可见雨滴从 0 增至 150，雨声随之变强。再只取消“雨滴”图层：画面无雨，声音仍保留。

这个实验说明了什么？ 可复用的是绘制、调度、混音和参数控制；新场景仍需要重新设计构图、动作和声音配方。此例是独立编写的简化实现，没有接入原站引擎。原站公开脚本还包含更复杂的编曲、场景事件和输出能力：场景脚本 ↗ · 音乐脚本 ↗。
