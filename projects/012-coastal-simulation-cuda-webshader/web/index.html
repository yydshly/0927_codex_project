012 / 海岸模拟技术研究

水与岩石，
实时互动。

这套海岸系统用浅水算法计算水怎样冲滩、绕岩和退回，用三维渲染呈现白沫、短波与喷雾，再由 GPU 执行计算。适用范围是海岸浅水与固定环境的互动。

OUR UNDERSTANDING / 理解汇总

水遇到岩石和海岸，会发生什么？

水受到固定地形阻挡，沿低处流动、分流并退回。浅水模型计算这些变化，视觉层把状态呈现为浪、白沫、湿痕和喷溅。这里的“碰撞”指水流与固定环境的接触响应；岩石保持静止。

能力
海浪与固定岩石、海床和岸线接触后，水会受阻、分流、绕石、冲滩并退回；岩石本身不会被水推动。
呈现效果
浪涌、沿水流移动的白沫、细小波纹、撞击喷雾，以及退水后的湿沙与湿岩石会连续变化。下方用三个真实视角展示。
内部模块
地形和来浪输入 → 浅水求解 → 破浪湍流与泡沫 → 短波和水面重建 → 湿润、喷溅与光照 → GPU 调度、相机和诊断。
内部算法
交错网格浅水更新、动量平流、保正水量通量、湿干边界、泡沫输运与衰减、八组定向短波、法线与 GGX 高光、喷溅粒子更新；CUDA WebShader 编译为 WGSL，在 WebGPU 上计算，再由 Three.js 绘制。
使用场景
互动海岸网页、展陈与视觉原型，浅水及图形学教学，以及 GPU 数据管线研究。
可扩展产品方向
可配置并保存的海岸场景编辑器、可嵌入的互动海岸组件、算法教学实验台；自由地形接入、预设管理和设备适配仍需开发。
对我的意义
看懂水流方程、GPU 数据和最终画面如何连接，在源库已有的三维效果上逐步制作自己的海岸场景。

适用范围：二维浅水高度场生成三维海岸画面。移动船只、浮力、侵蚀、倒水、管道流动和完整翻卷浪，需要额外模型。012 已验证源库运行与单处新增礁石；自由地形和完整场景编辑器仍待开发。

01 / THE ACTUAL CHANGE

变化发生在计算，
也发生在数据流。

原版就已用 GPU 绘制三维海岸。移植版的核心，是把更多动态状态交给 GPU 计算，并避免每帧跨 CPU 往返。

原版 / coastal-simulationCPU 求解 → GPU 绘制
外海波浪→Worker / Wasm 求解→水面与材质数据→Three.js 绘制

方程、场景和原有湿沙/泡沫效果来自原项目。本页以你已有的 008 研究为对照。

移植版 / WebGPU residentGPU 求解 → GPU 绘制
CUDA 源 → WGSL→WebGPU 求解→GPU 表面重建与共享资源→Three.js 绘制

普通帧中，九个演化场不依赖 CPU 回读、重建和重新上传。JavaScript 仍管理交互、相机和任务提交。

执行变化

模拟场常驻 GPU，减少搬运与 CPU 打包。

效果变化

新增动量、破浪湍流、定向短波和更丰富的岩石喷雾。

没有变成

原生浏览器 CUDA，也没有变成完整三维流体求解器。

01 / 海岸输入

地形与障碍网格

程序化海床、岩石遮挡和 CUDA 障碍场。

可见岩石与求解器中的固体区域相互对应；换场景时两套表示必须一起更新。
02 / 海岸输入

外海入射波

边界行给近岸水体持续输入波动。

推动浪向岸边传播；海况、潮位与方向控制逐渐影响岸线状态。
03 / 海岸输入

辐射边界与材料噪声

边界系数与 512 × 512 材料噪声纹理。

降低边缘硬反射，并给岩石、地表材质提供变化。
04 / 水流求解

浅水高度场

水深与两个水平流速分量构成主体状态。

能计算冲滩、退水和绕石；每个水平位置只有一个水面高度，不能形成完整翻卷浪腔。
05 / 水流求解

动量平流

交错网格面流速先随水流搬运。

让潮流与回流携带自身动量，再进入压力及保正水量输运步骤。
06 / 水流求解

水量与湿干边界

保正通量、岸线干湿切换与条件平滑。

水沿坡面上冲再退下，同时避免数值更新把局部水深推成负值。
07 / 水流求解

破浪湍流储量

陡波和岩石撞击产生、输运与耗散。

浪头经过后白沫仍会短暂存在；这是一层视觉近似，不是解析三维湍流。
08 / 表面效果

泡沫生成与输运

白沫随流移动、变化并衰减。

能看到与浪头、岩石接触相关的泡沫丝线、泡沫块与清水间隙。
09 / 表面效果

八组定向短波

色散速度与二次谐波塑造波峰。

强化近景碎波与波峰；细节在浅水、泡沫处和网格边缘淡出，不增加求解器水量。
10 / 表面效果

水面重建与法线

GPU 重建湿干水面并保持连续法线。

把模拟网格变成绘制所需的高度、材质与流速纹理，再在渲染帧间插值。
11 / 表面效果

水色与太阳高光

粗糙度相关 GGX、高光过滤与背光浪尖。

清水、白沫、亮波峰呈现不同反光；这些是视觉着色，不改物理状态。
12 / 岸线接触

湿沙与薄水膜

水膜快退、湿度慢退的双时间尺度。

水冲过之后，沙面先失去亮反光，再逐渐恢复原本颜色。
13 / 岸线接触

湿岩石与水位接合

湿润保持、岩内表面外推与深度裁切。

岩壁水位线附近渐暗；尽量避免水面以粗网格台阶穿出岩石。
14 / 岸线接触

撞击驱动喷雾

水滴、密集碎雾和扩散薄雾三层。

作者设置每块岩石 384 槽、共 5376 槽；静水不会无故持续喷射。
15 / 运行与诊断

GPU 常驻互操作

共享缓冲区、纹理拷贝与 Three.js r185 适配。

普通渲染帧不回读完整模拟场；适配器依赖指定 Three.js 版本，迁移时需核对接口。
16 / 运行与诊断

固定步长调度

60 Hz 流体、30 Hz 平流与双纹理插值。

模拟按确定步长推进，显示帧率可变化；调度边界保证相互依赖的步骤按序运行。
17 / 运行与诊断

环境与自由飞行

海况、风向、潮位、云量、光照、画质及预设视角。

鼠标与键盘可自由观察浪、岩石和湿沙；飞行无碰撞、高度跟随或高度限制。
18 / 运行与诊断

FPS 与分级诊断

页面帧时、`?profile` 与 CUDA 缩减摘要。

可查看运行后端、资源计数与小型诊断；正常帧依旧不依赖完整状态同步。

IMPORTANT BOUNDARIES

适用范围先说清。

二维浅水高度场

每处只存一个水面高度；不是有翻卷浪腔的三维水体。

视觉细节不等于水量

短波只细化表面；泡沫与湍流是有界的视觉近似。

WebGPU 是硬要求

没有 CPU、Wasm、WebGL 回退；不支持时无法运行本演示。

固定场景与适配版本

地形和障碍关联紧密；GPU 互操作适配钉在 Three.js r185。
