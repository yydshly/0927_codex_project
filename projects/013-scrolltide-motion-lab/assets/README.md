# 图片来源

- `cover.jpg`：本项目原创 Eagle 视频的一帧，保留作演示素材；当前仓库和统一站点封面已改为源站 Vesper 截图。
- `cover.svg`：早期制作的六种动效技术路线示意图，保留作技术总览素材。
- `source-vesper.png`、`source-aeroforce.png`、`source-apogee.png`、`source-eagle.png`、`source-ora.png`：2026-09-27 以 1440×900 浏览器视口直接截取的 Scrolltide 公开样例页面。仅用于标明研究对象和视觉参照；保留源站导航、样例标题和预览区域。对应原页分别为 [Vesper](https://www.scrolltide.co/templates/vesper)、[AeroForce](https://www.scrolltide.co/templates/aeroforce)、[Apogee](https://www.scrolltide.co/templates/apogee)、[Eagle](https://www.scrolltide.co/templates/eagle)、[Ora](https://www.scrolltide.co/templates/ora)。站方拥有其页面与预览素材的权利。
- 网页中的金雕、腕表、山景与摄影原始画面位于 `web/media/`，由内置 ImageGen 生成；视频与逐帧图片通过 `web/make_cinematic_media.py` 从这些原始画面制作。

五张源站截图用于引导图和索引封面。本项目的六个互动场景未使用上游网站的模板代码、付费素材或预览视频；它们由本地原创媒体和代码实现。
