01 / WHAT THIS PROJECT IS

研究的是网页空间展示。

Scrolltide 是提供动态网页模板、组件和 Shader 的作品库。本项目把其中的典型视觉效果拆成可观察、可操作的技术路线，并区分画面的空间感与真实实时 3D。

01 / 可见效果

影片式开场、滚动控制镜头、产品模型转动、视频与三维叠合、空间卡片、生成式光场。

02 / 本站模块

源站截图引导、六个原创互动实验、实时状态与验证按钮、技术路线和成本选型。

03 / 实现机制

视频时间轴、滚动到帧号的映射、Three.js 几何与相机、透明图层合成、CSS 透视、片元着色。

04 / 使用与扩展

适用于产品发布、品牌叙事、作品集与互动展陈；可延伸为三维商品展示器和可复用的滚动叙事组件。

对你的价值：先看到目标画面，再亲手验证它如何运动，最后判断真实三维是否必要，以及素材、性能和开发成本。

03 / THE DECISION

需要什么控制，就选什么管线。

不是谁更“高级”，而是画面需要什么交互、能承担多少制作与运行成本。

01只需要高质量镜头？

选视频。制作容易控制，播放稳定；画面内容不可改变视角。

02滚动必须精确控制镜头？

选图片序列。滚动可以逐帧定位，但帧数增加会带来加载成本。

03用户要真正绕着物体看？

选 Three.js。几何、灯光与相机实时响应，需要处理模型和 GPU 性能。

04背景电影感，前景还要互动？

选混合叠层。合成灵活，但视频和 3D 会同时消耗资源。

05只是卡片和界面立体？

先试 CSS 3D。文字和交互保留在 DOM，代码与资源更轻。

06抽象光色要连续变化？

选 Shader。用公式生成无限流动的背景，无需预制一段影片。
