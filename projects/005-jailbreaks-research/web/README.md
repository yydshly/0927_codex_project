# Jailbreaks 越狱研究指南

[在线网页](https://yydshly.github.io/0927_codex_project/005-jailbreaks-research/#overview) · [本地网页入口](index.html) · [项目概览](../README.md) · [研究数据](../data/source-index.json)

中文单页网站，首页以加粗的「能力 / 呈现效果 / 使用场景 / 可扩展方向 / 对我的意义」摘要展示结论，并嵌入完整引导图。后续章节说明越狱目标、文本机制、使用场景、承载方式、效果判断、个人意义和来源依据。场景包含受限代码请求、内容限制、越狱防护评估和用户此前的无人机问题；可切换场景、复制研究记录模板、展开 25 个文件的原文清单。

## 直接阅读

本地预览请使用下方服务器；引导图从子项目 `assets/` 读取。构建后可直接打开 `dist/index.html`。样式、脚本、引导图和来源数据均使用相对路径，不依赖外部字体、服务或 API 密钥。移动构建产物时需保留 `assets/` 目录。

复制记录模板优先使用浏览器剪贴板 API；若直接打开文件时浏览器不支持，会选中文本并提示手动复制。页面中的 GitHub 来源链接需要联网。

## 本地预览

需要 Node.js，无第三方依赖，无需安装软件包。在本目录运行：

```sh
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5185/`。服务器只监听本机；停止服务器后，本地地址不再可用，仍可直接打开 HTML 文件。

## 检查和构建

```sh
npm run check
npm run build
```

构建会从 `../data/source-index.json` 同步 `source-data.js`，并复制网页资源到 `dist/`。产物使用相对路径，可以放在子目录托管；`dist/` 是忽略的构建产物。研究结论更新时还需同步页面正文中的数量、日期和引用，不能只更新 JSON。
