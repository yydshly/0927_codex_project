# 项目图片

将本项目截图和示意图放在此目录，优先使用 PNG、JPEG 或 WebP；需要动态图时可使用 GIF，矢量图可使用 SVG。

- 首页封面建议命名为 `cover.webp`，根据内容选择清晰且大小适当的图片。
- 在上一层 `project.json` 中设置 `"cover": "assets/cover.webp"`，并填写说明内容的 `cover_alt`。
- 更多图片按用途命名，例如 `overview.webp`、`settings.png`、`architecture.svg`。
- 在子项目 README 中引用图片时使用 `assets/文件名`，每张图配一句说明。
- 引用上游图片时在这里记录来源；实测截图标明对应版本。

当前尚无图片，不添加虚构截图或失效的占位图片链接。
